🎓 HOW TO USE THE MODULE

Installation:
  1. Copy vendor_management folder to Odoo addons directory
  2. Update apps list: Apps → Update Apps List
  3. Search for "Vendor Management"
  4. Click Install (demo data will load automatically)

Access:
  Navigate to: Vendor Management menu (top menu bar)

Key Features Access:
  ├─ Vendors:           Vendor Management → Vendors → Vendors
  ├─ RFQs:              Vendor Management → Procurement → RFQs
  ├─ Quotations:        Vendor Management → Procurement → Quotations
  ├─ Purchase Orders:   Vendor Management → Procurement → Purchase Orders
  ├─ Quality (GRN):     Vendor Management → Quality → Goods Receipt Notes
  ├─ Quality (NCR):     Vendor Management → Quality → Non-Conformance Reports
  ├─ Invoices:          Vendor Management → Finance → Vendor Invoices
  ├─ Payments:          Vendor Management → Finance → Vendor Payments
  └─ Configuration:     Vendor Management → Configuration

Demo Data Navigation:
  See DEMO_DATA_GUIDE.md for detailed walkthrough
